| 05:10 | Actions 기록 확인 | GitHub 예약 실행이 **4시간 동안 한 번도 안 돌았음** |
| 05:20 | GitHub 토큰 발급 (이 저장소 Actions 실행 권한만) | Cloudflare에 `GITHUB_TOKEN`으로 등록 |
| 05:30 | Worker에 10분마다 깨어나는 알람(`scheduled`) 추가 | GitHub에 "알림 작업 실행해" 요청 |
| 05:50 | 알람 첫 실행 확인 | `이미 실행 중 - 건너뜀` (정상) |

### 바뀐 구조

| 이전 | 이후 |
| --- | --- |
| GitHub가 15분마다 알아서 실행 (실제로는 수십 분~몇 시간 밀림) | **Cloudflare가 10분마다 정시에** GitHub에 실행 요청 |

이미 실행 중이면 요청하지 않아서 경기 감시가 중복되지 않는다.

### 배운 것

- GitHub 예약 실행은 정시를 보장하지 않는다. 새로 만든 예약은 한동안 아예 안 돌 수도 있다.
- `wrangler secret put` 뒤에는 **이름**(`GITHUB_TOKEN`)을 쓰고, 값은 다음 질문에 넣는다.
- 토큰은 권한을 좁게 주면(이 저장소 Actions만) 유출돼도 피해가 작다.

### 확인된 것

| 항목 | 결과 |
| --- | --- |
| Cloudflare 알람으로 감시 시작 | 성공 (어제처럼 늦지 않음) |
| 두 경기 동시 감시 | 성공 |
| 친구와 같은 선수 등록 | 메시지 하나에 `@peponin @yunsu` 함께 멘션 |
| 경기 후 리포트 지연 | 1분 이내 |
| 골·교체 투입 실시간 지연 | 내 선수 골·투입이 없어서 아직 미확인 |

### 지연 측정 도구

ESPN이 이벤트를 기록한 실제 시각을 보는 `experiments/check_timing.py`를 만들었다. 킥오프가 실제와 거의 같은 시각에 기록돼서, ESPN 반영은 거의 실시간으로 보인다. 골 알림 목표(최대 3분)도 달성 가능할 것으로 예상한다.

`experiments` 폴더 안 파일에서 `import espn`이 안 되는 문제는 맨 위에 `sys.path.append(".")`를 넣어 해결했다.

## 11/1

### 컵 대회 감시 추가

ESPN은 팀 ID가 대회와 상관없이 같아서, "선수의 리그 경기"가 아니라 "선수 팀이 나오는 경기"를 찾도록 바꿨다.

| 대회 | ESPN 코드 |
| --- | --- |
| 4대 리그 | `eng.1`, `esp.1`, `ita.1`, `ger.1` |
| 유럽대회 | `uefa.champions`, `uefa.europa`, `uefa.europa.conf` |
| 국내 컵 | `eng.league_cup`, `eng.fa`, `esp.copa_del_rey`, `ita.coppa_italia`, `ger.dfb_pokal` |

| 파일 | 바뀐 것 |
| --- | --- |
| `main.py` | 대회 목록 추가, 실행 시작 때 **오늘 경기 있는 대회만** 골라서 반복 확인 (요청 수 절약) |
| `espn.py` | 알림 하단에 팀 소속 리그 대신 **그 경기의 대회 이름** 표시 |

2024 테스트 경기로 기존 알림 7개가 그대로 오는 것을 확인했다. 실제 챔스·컵 경기 확인은 다음 경기에서 한다.
