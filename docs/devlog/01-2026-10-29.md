10/27에는 계획서를 작성했고(기능, 무료 범위, 실행 시간대 등), 이 일지는 그 이후 실제 개발 기록이다.

### 실전 테스트에서 알게 된 것

- ESPN 명단은 킥오프 약 50분 전에 들어오고, 홈팀이 먼저 들어온다.
- 골·교체 알림이 실제보다 약 8분 늦게 왔다. ESPN이 이벤트를 몇 분씩 모아서 반영하는 것으로 보인다.
- 선수별로 처리해서 알림 순서가 시간순이 아니었다 (59분 골이 57분 교체보다 먼저).

## 문제와 해결

가장 큰 문제는 데이터 소스였고, 나머지는 대부분 저장 누락이나 실행 위치 실수였다.

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| API-Football로 현재 시즌 조회 불가 | 무료 플랜은 2022\~2024 시즌만 | 개발은 2024 데이터, 운영은 ESPN 비공식 API |
| ESPN에 평점·패스·경합 없음 | ESPN은 기본 스탯만 제공 | 경기 후 리포트를 기본 스탯 + 경기 흐름으로 단순화 |
| 교체 IN/OUT 순서가 API마다 반대 | API-Football은 OUT이 먼저, ESPN은 IN이 먼저 | "벤치였던 선수가 교체에 나오면 투입"으로 판단 |
| 출전 시간이 10분인데 6분으로 계산 | ESPN 시간 값에 추가시간 미포함 | 화면 표시(`90'+5'`)를 직접 95분으로 변환 |
| ESPN `form`(최근 5경기)이 실제와 다름 | 조회 시점 기준 값으로 추정 | 날짜가 있는 `lastFiveGames` 사용 |
| 테스트 시 순위가 시즌 성적과 안 맞음 | `standings`는 조회 시점 순위 | 실제 운영은 경기 직전에 조회하므로 정상 |
| 실행해도 아무 일도 안 일어남 | 파일 저장 안 됨 (탭의 ●) | 저장 확인, 자동 저장 켜기 |
| 디스코드 멘션에서 `TypeError` | 사용자 ID를 따옴표 없이 넣음 | ID는 항상 문자열로 (`str()`) |
| `npm -v` 실행 안 됨 | PowerShell 스크립트 실행 차단 | 내 계정만 `RemoteSigned`로 변경 |
| `wrangler deploy`, `python kv.py` 실패 | 터미널 위치가 다른 폴더 | Python은 `player-notifier`, wrangler는 `bot-worker`에서 |
| `/알림설정` 응답 없음 | `commandName`을 선언 전에 사용 | `wrangler tail`로 에러 확인 후 코드 순서 수정 |
| Actions는 매번 새 컴퓨터라 `sent.json`이 사라짐 | 실행 간 파일 유지 안 됨 | 보낸 알림 기록을 KV에 저장 |
| 공개 저장소 60일 무활동 시 예약 실행 중지 | GitHub 규칙 | 주 1회 선수 사전 갱신 때 기록 파일 자동 커밋 |

## 현재 구조

사용자는 디스코드 명령어만 쓰고, 나머지는 전부 Cloudflare와 GitHub 서버에서 돌아간다. 비용은 0원이다.

```
[디스코드 봇] --/명령어--> [Cloudflare Worker] --저장--> [Cloudflare KV]
      ^                                              ^        ^
      |                                              |        |
  봇 알림 + 멘션                           설정 읽기·기록   선수 사전
      |                                              |        |
[ESPN 비공식 API] <--경기 조회-- [GitHub Actions 알림]   [GitHub Actions 갱신]
      ^                                                        |
      +------------------ 팀별 선수 명단 (주 1회) ---------------+
```

Worker가 명령어로 받은 설정을 KV에 넣고, GitHub Actions가 그 설정을 읽어 ESPN을 확인한 뒤 옵션 켜 사람만 멘션해서 알린다.

| 파일 | 역할 |
| --- | --- |
| `main.py` | 감시 목록 만들기, 경기 찾기, 상태별 반복 확인 |
| `espn.py` | ESPN 데이터 받기·정리 (선수, 경기 정보, 이벤트) |
| `alerts.py` | 알림 내용 만들기, 옵션 켜 사람만 골라 보내기 |
| `discord_notify.py` | 봇 토큰으로 임베드 + 멘션 전송 |
| `kv.py` | Python에서 Cloudflare KV 읽기·쓰기 |
| `build_player_db.py` | 4대 리그 선수 사전 만들기 + KV 업로드 |
| `register_commands.py` | 디스코드에 명령어 6개 등록 |
| `bot-worker/src/index.js` | 명령어 처리 (서명 검사, 자동완성, KV 저장) |
| `.github/workflows/notify.yml` | 알림 자동 실행 (15분마다) |
| `.github/workflows/update_db.yml` | 선수 사전 주 1회 갱신 |
| `experiments/` | 테스트·예전 버전 코드 (기록용) |
